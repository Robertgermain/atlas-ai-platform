# Atlas AI Platform

Atlas is a planned production-oriented, multi-agent deep-research platform and a hands-on AI/backend/cloud engineering portfolio project.

The repository currently contains the product baseline and is beginning local implementation. Code structure will be added through small, tested vertical slices so every folder and file has a clear purpose.

## Read in this order

1. `PROJECT_STATE.md` — what is true now and what happens next
2. `docs/RESEARCH.md` — candidate, market, and technology context
3. `docs/PRD.md` — what Atlas must accomplish
4. `docs/TESTING.md` — how software and AI behavior will be verified
5. `docs/TECHNICAL_DESIGN.md` — architectural decisions validated during implementation, followed later by the complete local-to-AWS design
6. `AGENTS.md` — rules for AI assistants working in the repository

## Current milestone

Establish a tested Python/FastAPI foundation locally. PostgreSQL-backed research jobs and AI workflow capabilities will follow incrementally. The comprehensive Visio and AWS design is deferred until working local components can be mapped to the cloud with evidence.
